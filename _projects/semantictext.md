A framework and playground for generative AI in Squeak. It integrates the OpenAI API for chatbots that can process and create text, images, and human speech, and implements a vector database for semantic search using text embeddings. SemanticText also augments various base tools of Squeak such as help browsers and Squeak Inbox Talk with "intelligent" searches, recommendations, and summaries.
